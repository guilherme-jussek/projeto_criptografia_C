## Sobre o Projeto

Projeto desenvolvido para a disciplina de Algoritmo e Pensamento Computacional.

O objetivo é unir conceitos de programação em C, criptografia simples e matemática aplicada em um único programa.

## Como funciona

O programa utiliza duas etapas de criptografia:

1. **Cifra de César:** deslocamento fixo de 3 posições;
2. **Fibonacci:** utiliza a sequência de Fibonacci para realizar novos deslocamentos.

A sequência utilizada é:

```text
1, 1, 2, 3, 5, 8, 13...
```

O resultado final é uma palavra modificada pelas duas etapas.
